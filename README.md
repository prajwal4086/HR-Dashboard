# 📊 HR Analytics Dashboard

An interactive HR Analytics Dashboard built using **Microsoft Excel** to analyze employee data and provide meaningful insights into workforce performance, employee distribution, and attrition trends.


## 🎯 Project Objective

The goal of this project is to transform raw HR data into actionable insights that help organizations make better workforce and business decisions.


## ✨ Key Features

* 👥 Employee Distribution Analysis
* 📉 Attrition Rate Analysis
* 🚻 Gender Diversity Insights
* 🏢 Department-wise Analysis
* 📊 Job Level Distribution
* 📌 KPI Tracking
* 🎛️ Interactive Dashboard with Slicers and Filters


## 🛠️ Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Data Cleaning & Transformation
* Data Visualization


## 📚 Skills Demonstrated

* Data Analysis
* Dashboard Development
* Business Analytics
* KPI Reporting
* Data Visualization
* Analytical Thinking
